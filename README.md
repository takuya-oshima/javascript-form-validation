# javascript-form-validation

JavaScript（フレームワークなし）で、お問い合わせフォームの入力チェックを実装しました。

## 使用技術

HTML / CSS / JavaScript

## 実装した内容

- お名前・会社名・メールアドレス・ご相談内容・ご予算・ご希望の納期の入力チェック
- 入力欄からフォーカスが外れたタイミングでチェックし、項目ごとにエラーメッセージを表示
- メールアドレスの形式チェック（正規表現）
- 必須項目がすべて正しく入力されるまで、送信ボタンを押せないように制御

## 学んだこと

- `blur` や `change` イベントを使った、入力途中でのリアルタイムなチェック
- エラー時の見た目（枠線の色、メッセージ）と、送信ボタンの状態の切り替え
